# Security Policy

## Reporting a Vulnerability

**Please do NOT open public GitHub issues for security vulnerabilities.**

Publicly disclosing a security vulnerability can expose the application, infrastructure, and users to unnecessary risk before a patch can be developed and deployed.

## How to Report

We welcome responsible security research and appreciate early disclosures. You can report security vulnerabilities through either of the following methods:

1. **GitHub Private Vulnerability Reporting (Recommended)**
   If enabled on this repository, navigate to the **Security** tab at the top of the repository page and click **Report a vulnerability**. For details on how this feature works, see the [official GitHub documentation on Private Vulnerability Reporting](https://docs.github.com/en/code-security/security-advisories/working-with-repository-security-advisories/about-private-vulnerability-reporting-for-repositories).
   
   *(Note for Maintainers: Private vulnerability reporting must be enabled under **Settings** → **Code security**).*

2. **Email Disclosure (Fallback)**
   If Private Vulnerability Reporting is unavailable or you prefer email, send details directly to our team email:
   [cscu.okanagan@gmail.com](mailto:cscu.okanagan@gmail.com)

## Information to Include in a Report

To help us assess and resolve the issue quickly, please include:

- A brief description of the vulnerability and its potential security impact.
- The specific component, page, API endpoint, or feature affected.
- Step-by-step instructions to reproduce the issue.
- Any relevant logs, screenshots, or proof-of-concept code (please ensure real secrets, tokens, and personal information are redacted).

### Responsible Disclosure Guidelines

When investigating potential security issues, please:

- Do **not** attempt to access or modify data belonging to real users.
- Do **not** execute denial-of-service (DoS) attacks or degrade service performance.
- Do **not** share or expose sensitive credentials, API keys, or secret tokens.
- Maintain confidentiality until a fix has been released.

## Expected Response

- **Acknowledgement:** Maintainers aim to acknowledge receipt of security reports within a few business days.
- **Assessment & Updates:** We will investigate the reported issue, assess its impact, and provide updates regarding a fix or mitigation timeline.

Thank you for helping keep the CSCU website and community safe!
